# Sample solutions — deliberately partial

This directory holds **sample-solution guidance**, kept out of the student-facing briefs under `docs/projects/` and
`docs/capstone/proposals/`.

The separation is deliberate and is part of the assessment design: a student should meet the problem before the
answer. Nothing here is a complete submission.

## What is here

| File | Covers | What it is not |
|---|---|---|
| `exemplars.md` | One worked excerpt per rubric criterion for mini and major projects | Mark schemes with model answers |
| `common-failures.md` | The eight ways these projects usually fail, with the fix | A checklist that earns marks on its own |
| `mp01-reference/` | A partial reference for MP01: manifest builder and verifier only | The duplicate checks, provenance or report that MP01 requires |

## Standing rules

1. **No complete solutions.** Where a reference implementation exists, it stops before the part the project is
   actually assessing — for MP01, the failure taxonomy, label integrity and decision note are absent.
2. **Excerpts, not essays.** An exemplar shows one paragraph at *Exemplary* and its weaker twin at *Developing*,
   so the difference in judgement is visible.
3. **Nothing here replaces the brief.** If a brief and this directory disagree, the brief governs.

## For instructors

These files are not published in the site build: `mkdocs.yml` excludes `projects/solutions/` from `docs/`, and this
directory sits outside it entirely. Reuse them for marking calibration, not as handouts.
