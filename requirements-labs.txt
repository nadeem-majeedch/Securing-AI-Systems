# Student laboratory environment.

# Every direct dependency is pinned to the version this course was validated
# against. Do not widen a pin without re-running every laboratory and every
# notebook: the labs quote exact numbers (AUC 0.875, robust accuracy 0.063,
# adversarial success rates), and a library change can move the third decimal.
#
# Validated on: Python 3.14.7, Windows 11, four-core CPU, no GPU, no network.
# Also resolvable on Python 3.12. All 32 lab solutions and all 34 notebooks

#
#   python -m venv .venv
#   # activate, then
#   python -m pip install --upgrade pip
#   python -m pip install -r requirements-labs.txt
#   python scripts/check_env.py
#
# PyTorch: the pin below resolves to the platform-appropriate wheel from PyPI.
# For an explicitly CPU-only install, use the official index first:
#
#   python -m pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cpu

# Unused-by-design: this file contains only libraries that a laboratory, a
# notebook, or the documented student workflow actually imports. torchvision,

# removed in the Phase 14 audit: no lab or notebook imports them, and every
# technique they would provide is implemented in the course's own code.
